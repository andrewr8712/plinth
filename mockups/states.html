Behaviour the pictures can't show

CaseRule
Command timeoutsState commands 3 s, listallinfo 20 s, art 15 s, idle unbounded. Two consecutive failures on state → Unreachable. The UI never waits on the socket; it renders the last known state with a stale marker.
ReconnectBackoff 0.5 s → 16 s, jitter ±20 %, reset on success. Countdown replaces "Retrying in 8s" each tick; Retry now cancels the wait. No reconnect attempts while the screen is off and no service is running.
Art failureACK 50 → initials plate + 7-day negative cache. Timeout → plate, no negative, retried on next visit. Never a spinner longer than 15 s, never a retry loop.
Missing level dataMeter keeps its 96×34 box and says "No level data — not in the loudness scan". Never animates. When the envelope is stale (library db_update moved on) the box says "Loudness data is older than the library".
Long titles2-line clamp, 64→48 px above 28 characters, overflow-wrap:anywhere for unbroken strings. Artist 1 line + ellipsis. Album grid titles 2 lines, fixed metadata block so grid baselines stay level.
Seek gesturesOne pointer owns the drag. On pointercancel, lostpointercapture, blur, or a second pointer landing: abandon the drag, restore the last confirmed position, send nothing. Next drag works without a reload.
Transport double-tapSend once; ignore further taps for 250 ms or until status returns, whichever is first. Optimistic state flips immediately, reconciles on the next status.
Empty libraryDistinguish "no tracks" from "cannot reach share": if stats reports 0 songs, say the share is down and offer Retry, not a scan.
i18n budgetAll text containers flex; +35 % width budget for German. Logical properties throughout (padding-inline, border-inline-start), digits and times via Intl, no hardcoded Western numerals in RTL builds.
AccessibilityEvery control is a 48 dp target with an accessible name; state changes announce through aria-live="polite"; the meter exposes its dB values in the label; disabled transport is aria-disabled, not hidden.
FocusKeyboard/switch order follows visual order: device status → transport → queue. The sheet traps nothing; back closes it. Focus rings use the accent at 2 px with a 2 px offset.
